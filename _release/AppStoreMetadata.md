## Description (4,000 文字以内)

```
建築士単語帳は、一級・二級建築士試験で問われる重要単語を、表裏カード形式で効率的に覚えるための学習アプリです。

【特徴】
・表に単語、裏に意味と詳細解説のシンプルなフラッシュカード形式
・「計画」「環境・設備」「法規」「構造」「施工」のカテゴリ別学習
・お気に入り・苦手・暗記済みのフィルタで効率復習
・自分でオリジナル単語の追加・編集・削除が可能
・全単語シャッフル学習で本番に近い形で確認
・通信不要、すべてオフラインで使える
・データはすべて端末内に保存、アカウント登録不要

【遊びかた】
1. ホームから学習したいカテゴリを選ぶ
2. カードをタップで表→裏を確認
3. 「お気に入り」「苦手」「暗記済み」をワンタップで仕分け
4. 苦手単語だけを集中して復習

【こんな方におすすめ】
・一級・二級建築士試験の受験生
・スキマ時間で建築用語を覚えたい方
・市販単語帳より自分のペースで学びたい方
・通学・通勤中にスマホだけで勉強したい方

【課金について】
基本無料でお使いいただけますが、画面下部にバナー広告を表示します。
アプリ内課金「広告削除」(280円)をご購入いただくと、広告を恒久的に非表示にできます。
購入は Apple StoreKit を通じて処理され、開発者がクレジットカード情報を取得することはありません。
機種変更時は「購入を復元」から同じ Apple ID で復元できます。

【プライバシー】
本アプリは個人情報を一切収集しません。学習データはすべて端末内にのみ保存されます。
広告は Google AdMob で配信され、IDFA を用いた行動ターゲティングは行いません(非パーソナライズ広告のみ)。

ご質問・ご要望:
kinniku.kin.gin@gmail.com
```
